# 萨尔瓦多 · 大棚蔬菜改造方案

把 Rancho 的主要作物从谷物换成设施蔬菜，依据有两条：萨尔瓦多的气候约束，
和附件视频里那座已经建起来的竹架大棚。下面先写场地判读，再写模型怎么改，
最后是茬口、水肥与产量校验。

## 1. 场地判读

视频里的棚是「萨尔瓦多智慧农业专家顾问项目」的示范棚，棚内尚未定植，土面裸露，
说明这是刚建好、准备上茬的状态。

| 判读项 | 观察到的事实 | 落到模型 |
| --- | --- | --- |
| 地形 | 坡地，棚沿等高线布置，棚外土路明显低于棚脚 | `terrain=slope`，`slope_pct=6.0` |
| 棚型 | 竹木拱架，跨度约 6 m、长 30–40 m，肩高约 1.8 m | 18 × 40 格（每格 1 m），相当于三栋并排加通道 |
| 覆盖 | 顶部黑色遮阳网，四周白色防虫网，网脚压塑料裙边 | `protected=True`，`cover_transmission=0.55`（膜 0.85 × 遮阳网 0.65） |
| 土壤 | 红棕色、板结、夹碎石，坡面有细沟冲刷 | `soil=andisol`（安山土），空间变异 0.45 |
| 灌溉 | 棚外 PE 主管与盘起的滴灌带 | 滴灌，覆盖 90 %，10 mm/次 |
| 监测 | 棚内挂蓝板与黄板 | 蓟马、粉虱/斑潜蝇监测；病害按 IPM 管理 |
| 周边 | 香蕉、林木、咖啡与玉米地块 | 天然风障，同时也是粉虱与病毒源 |

## 2. 气候依据

萨尔瓦多太平洋坡地（海拔 500–1000 m）的农业气候可以概括为三点：

| 要素 | 量级 | 对蔬菜的含义 |
| --- | --- | --- |
| 气温 | 年均 23–27 ℃，年较差仅 3–5 ℃ | 温度不是限制因子，番茄可全年生长 |
| 降水 | 1500–2000 mm，其中 80–90 % 集中在 5–10 月 | 11 月–4 月旱季必须依赖灌溉 |
| 辐射 | 18–22 MJ/m²/d，旱季更高 | 强辐射 + 高温导致番茄落花、日灼 |
| 湿度 | 70–85 %，雨季近饱和 | 晚疫病、青枯病、灰霉高发 |

结论是：**限制因子不是冷，而是雨季病害、旱季水分和强辐射高温**。大棚恰好对症：

1. **避雨**：切断晚疫病与细菌性病害的雨水传播，叶面结露时间缩短。
2. **遮阳**：透光降到 55 %，正午冠层温度可降 2–4 ℃，提高坐果率。
3. **防虫网**：40–50 目阻隔粉虱，压低番茄黄化曲叶病毒（TYLCV）压力。
4. **滴灌**：地表蒸发与深层渗漏同时减少，旱季用水约为漫灌的一半。

## 3. 模型改动

| 文件 | 改动 |
| --- | --- |
| `rancho/scenario.py` | 作物加 `tomato`/`cucumber`/`lettuce`，气候加 `tropical`，土壤加 `andisol`；新增 `protected`、`cover_transmission`、`slope_pct`、`latitude`/`longitude`；新增两个萨尔瓦多预设 |
| `rancho/climate.py` | 气候参数改为 `ClimateProfile`；降雨概率按余弦做季节调制（这是热带两季的关键）；棚内降雨置零、辐射乘透过率、风速 0.2 m/s、湿度 +5 |
| `rancho/vegetables.py` | 三个蔬菜插件：热时间物候（定植到采收）、吊蔓限高、结果期冠层继续更新 |
| `rancho/agronomy.py` | 根区深度、Kc、允许消耗比例按作物取（`CROP_WATER`） |
| `rancho/engine.py` | 插件注册表、坡度的实际取值、经纬度、棚内气象参数 |
| `rancho/frames.py` | 产量改为「干物质 × 收获指数 ÷ 干物质率 × 商品率」，即鲜重可售产量 |

棚内小气候不是事后修正，而是直接写进逐日气象：CropForge 的 FAO-56 ET₀ 因此
按棚内辐射与风速计算，结果才站得住。实测同一配置下，棚内 ET₀ 均值 1.98 mm/d，
露天 3.42 mm/d，为露天的 58 %。

## 4. 茬口安排

| 茬口 | 作物 | 定植 | 拉秧 | 模型 `days` | 安排理由 |
| --- | --- | --- | --- | --- | --- |
| 旱季主茬 | 番茄 | 11 月上旬 | 次年 3 月中 | 130 | 避开雨季病害，光照与温差最有利于坐果 |
| 过渡茬 | 黄瓜 | 3 月中 | 5 月底 | 80–90 | 生长期短，赶在雨季前收完 |
| 夏季短茬 | 生菜 | 6 月 | 8 月初 | 60 | 遮阳网下降温，短周期规避高温抽薹 |
| 雨季休整 | 绿肥 / 土壤消毒 | 9 月 | 10 月 | — | 淹水或太阳能消毒，压低线虫与土传病原 |

模型里番茄与生菜各有完整预设；黄瓜插件已注册（`cucumber`），
需要时把 `crop` 换成 `cucumber` 再给 `days≈85` 即可。

## 5. 水肥

| 项目 | 方案 | 模型取值 |
| --- | --- | --- |
| 灌溉方式 | 滴灌，一畦一条滴灌带，压力补偿滴头 | 覆盖 90 %，10 mm/次，阈值 26 % |
| 灌溉量 | 定植期 1–2 L/株·日，盛果期 2–3 L/株·日 | 全季 288 mm |
| 氮 | 280 kg N/ha，基肥 30 % + 5 次追肥 | `fertiliser_kg_ha=280`，按季分 6 次 |
| 磷钾 | N : P₂O₅ : K₂O ≈ 1 : 0.4 : 1.6 | 模型只算氮，磷钾按经验配比 |
| EC / pH | EC 2.0–2.5 mS/cm，pH 5.8–6.2 | — |
| 安山土注意 | 磷固定强，磷肥条施或穴施；交换性钙镁偏低，注意补钙防脐腐 | — |

## 6. 产量校验

| 作物 | 模型输出 | 区域参考 |
| --- | --- | --- |
| 番茄 | 62.7 t/ha 鲜重，11.7 t/ha 干物质，474 g/株，峰值 LAI 3.2，株高 185 cm | 设施番茄 50–80 t/ha |
| 生菜 | 43.8 t/ha 鲜重，3.1 t/ha 干物质，42 g/株，峰值 LAI 2.6 | 设施叶菜 30–45 t/ha |
| 对照（同参数露天） | 70.3 t/ha，ET₀ 3.42 mm/d | 露天需要更多灌溉且雨季病害不可控 |

棚内产量低于露天对照，是遮阳 55 % 透光的直接代价；真实收益来自雨季可生产、
商品率更高与价格溢价，这部分不在模型里。

## 7. 风险与模型局限

1. **棚温没有闭环**：模型用辐射、风速与湿度近似棚内小气候，没有棚体热平衡，
   正午棚温可能被低估。若加侧窗或强制通风，应相应提高 `cover_transmission` 或降密度。
2. **病害不反馈生长**：CropForge 的 SIR 引擎只输出严重度，不减少生物量，
   因此番茄预设默认关闭病害，避免「图上绝收、产量照旧」的矛盾。
3. **坡地排水**：6 % 坡 + 棚檐集中汇水，棚脚需截水沟，否则坡下棚脚易积水烂根。
4. **连作障碍**：茄科连作线虫与青枯病风险高，必须按第 4 节轮作。
5. **采后**：当地冷链薄弱，损耗主要发生在采后而非田间，模型不覆盖。

## 8. 复现

```bash
uv run rancho simulate --preset salvador-greenhouse --out runs/salvador-greenhouse.json
uv run rancho simulate --preset salvador-leafy --out runs/salvador-leafy.json
uv run rancho dev        # 界面里切换预设，或直接打开 ?preset=salvador-greenhouse
```
